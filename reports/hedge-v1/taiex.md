# 期貨避險回測：發行量加權股價指數（TAIEX）

- 資料：2005-04-06 ~ 2026-11-11，5313 個交易日（研究資料截止 2026-11-11）
- 選參期：至 2019-01-01 前；檢驗期：2019-01-01 起
- 版本：轉弱程度 `pw-v1`、避險 `hedge-v1`；避險工具：TX 近月
- 股票部位報酬：加權股價報酬指數（含息）
- 產生時間：2026-11-12T08:00:12+00:00

## 設計

- 股票部位一直 100%；價格趨勢轉弱程度達「明顯轉弱」以上時，放空 TX 近月合約，名目 = 組合市值 × 避險比例；其他時候不避險。
- 期貨用一般時段實際成交價；最後交易日的前一日收盤轉倉。正逆價差與轉倉價差直接反映在損益中。
- t 日收盤決定，t+1 日開盤以期貨開盤價調整；成本：單邊 0.05%（名目），轉倉算兩腳。
- 恢復條件：`score3` 轉弱程度連續 3 日低於目前層級；`above_ma20` 收盤站回 20 日線；`above_ma20_ma5up` 收盤站回 20 日線，且 5 日線上揚
- 選參規則（事先固定）：選參期報酬/回撤最高。**本次選出：避險比例 20%、恢復條件 `above_ma20`。**
- 資料完整性：股票報酬缺 0 日、期貨報酬缺 0 筆（缺值以 0 計）、期間轉倉 259 次

## 注意事項

- 檢驗期對「只在明顯轉弱才動作」這個設計不是完全乾淨的（來自 bt-v1 的全期分析）；乾淨的驗證是前向紀錄。
- 避險部位假設每日調整口數維持固定比例；實際口數是整數（小台、微台可以降低誤差）。
- 不計保證金的資金成本與現金利息；放空期貨需要準備保證金與追繳緩衝。
- 大盤回測不等於個股組合；個股組合的避險比例需要依 beta 調整。
