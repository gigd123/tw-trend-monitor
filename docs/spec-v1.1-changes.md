# 規格 v1.1 修訂

本文件記錄 v1.0 規格的修訂項目。v1.0 原文未改動的部分繼續有效；本文件與 v1.0 衝突時，以本文件為準。

修訂依據：
- v1.0 規格審閱意見
- 資料來源實測結果（[data-feasibility.md](data-feasibility.md)）

---

## 1. 新增：可衡量的核心目標（取代 v1.0 §1.2 的描述性目標）

### 1.1 轉空事件定義
- **轉空事件**：加權指數收盤價從前一波高點回撤 ≥ 10%。
- **事件起點**：該波高點的日期。
- **確認點**：回撤首次達到 5% 的日期（用來衡量是否「提早」）。
- 同一波段內只算一次事件；指數創新高後才重新開始計算下一次。

### 1.2 衡量指標
| 指標 | 定義 |
|---|---|
| 提前天數 | 訊號首次達到警戒等級的日期，比「回撤 5%」早幾個交易日 |
| 誤報率 | 達到警戒等級後 20 個交易日內，沒有發生轉空事件的比例 |
| 漏報率 | 發生轉空事件，但在回撤達 5% 之前沒有出現警戒等級的比例 |

比較基準：單純「加權指數跌破 60 日線」規則。風險分數必須在提前天數或誤報率上優於這個基準，才算有價值。

### 1.3 回測提前
最簡回測（加權、櫃買、費半、Nasdaq 的均線規則）移到 **Phase 1 尾端**，不必等到 Phase 4。

## 2. 修訂：風險計分架構（取代 v1.0 §11.1、§11.5、§11.7）

### 2.1 單一刻度
只保留 0～100 分，等級由分數決定，Level 只是等級名稱：

| 分數 | Level | 名稱 |
|---|---|---|
| 0～19 | 0 | 低風險 |
| 20～39 | 1 | 留意 |
| 40～59 | 2 | 中度風險（＝回測用的「警戒等級」） |
| 60～79 | 3 | 高風險 |
| 80～100 | 4 | 極高風險 |

### 2.2 分類別計分，再加權合成
相關訊號不直接相加。每個時間尺度（短、中、長）各自計算：

1. 每個類別算出 0～1 的分數：
   - **趨勢**（加權、櫃買、費半、Nasdaq 的均線位置）
   - **廣度**（漲跌家數、新高新低）
   - **籌碼**（法人買賣超、外資期貨、融資與指數背離）
   - **國際金融**（VIX、美債、美元、台幣）
   - **總經**（僅長線使用）
2. 類別分數 × 類別權重，加總後 × 100。
3. 類別權重放在 YAML 設定檔，帶版本號；回測結果記錄使用的規則版本。

這樣自然做到 v1.0 要求的「類別權重上限」與「避免重複計分」。

### 2.3 資料缺漏
類別內有指標缺漏時，該指標不計入分母；整個類別缺漏時，類別分數沿用最後一次有效值並標示「過期」，**不得視為 0（風險解除）**。

## 3. 修訂：門檻一律用相對自身歷史的百分位

v1.0 中「快速貶值」、「融資高檔」、「空單連續增加」、「VIX 快速上升」等模糊描述，統一定義為：

| 描述 | 定義 |
|---|---|
| 快速變化 | N 日變化量位於過去 3 年（約 750 個交易日）的第 90 百分位以上 |
| 高檔 | 水位位於過去 3 年的第 80 百分位以上 |
| 連續增加 | 連續 3 個交易日增加，且 5 日累計變化位於第 80 百分位以上 |

N：短線 5 日、中線 20 日。百分位只用「當日以前」的資料計算，避免未來資訊。

VIX 保留 v1.0 的絕對門檻（20／25／30）作為顯示用參考線，但計分以百分位為準。
